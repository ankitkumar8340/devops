kubernates Architechure
1. Control plane: This is the brain which decides everything
2. Worker node: This actually runs the application.
3. Cluster: It is a group of computers working togther
4. Node: It is simply a machine it can be physical servers, virtual machines, EC@ instance, Azure VM, GCP VM. 
5. Pod: It is the smallest deployement units
6. Deployment: Pods are temporary and if a pod dies, k8s creates another though a deployment. Deployment manages pods
7. ReplicaSet: Suppose we want 3 pods and pod 2 dies. Replicaset creates pod 4 to balance it out.
8. Service: Static/ Permanent IP 
    Types of service:-
        1. ClusterIp:Internal Coummunication only
        2. NodePort Accible using PORT 300001
        3. LoadBalancer: Cloud Providers creates a public LoadBalancer
        4. Ingress: Instead of multiple load balancers, ingress routes the Traffic
        5. CongigMap: Stores non-sensitive configuration
        6. Secret: Stores sensitive data.
